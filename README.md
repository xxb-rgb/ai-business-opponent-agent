# AI业务反方陪练 Agent v0.1

一个面向业务表达、汇报、说服、面试等场景的 AI 业务智能体样板。

## 项目定位

本项目用于验证一个最小 Agent 闭环：

用户构造表达场景 → 反方智能体提出质疑 → 引用原文进行诊断 → 生成下一轮行动清单。

当前版本为规则与模板驱动的 MVP Demo，不接入真实用户数据，不处理隐私信息，不替代专业判断。

## 核心功能

- 测试包快速构造输入
- 反方智能体追问
- 引用原文诊断
- 雷达图能力呈现
- 角色化行动建议
- 导出行动卡图片

## 技术栈

- Next.js
- TypeScript
- Tailwind CSS
- html-to-image
- Vercel

## 当前版本边界

- 当前版本用于 MVP 路径验证
- 不接入真实大模型 API
- 不处理真实业务数据或隐私数据
- 不替代专业教练、顾问或业务负责人判断

## 后续迭代方向

- 接入大模型 API
- 接入真实业务 Rubric
- 使用脱敏样本验证输出质量
